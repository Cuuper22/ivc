# IVC Translation Research

Date established: 2026-05-24

This repository is a research workspace for the moonshot problem: building an evidence-grounded translation system for the Indus Valley Civilization script that can eventually approach the reliability expected from mature Ancient Egyptian translation.

That target is unfair by construction. Egyptian had bilingual texts, Coptic continuity, large corpora, and two centuries of formal scholarship. IVC does not. The point of this project is not to pretend those constraints disappear. The point is to make every uncertainty explicit, run experiments that can fail, and build only the parts of a translation system that the evidence can actually support.

## Operating Rule

No fluent fake translations.

Every output must be layered:

1. Graphemic reading: signs, direction, damaged/missing signs, sign-list authority.
2. Structural reading: position, formula class, numerical/metrological behavior, object type, iconographic context.
3. Semantic hypothesis: bounded meaning class with evidence and alternatives.
4. Linguistic hypothesis: only if constrained by the previous layers, and always compared against negative controls.
5. Confidence: calibrated, not rhetorical.

## Current Scope

This is not an app project, an OCR project, or a software-delivery project. It is an academic decipherment program.

Code is allowed when it helps the research: corpus checks, transcription audits, statistical probes, null models, comparator simulations, visualization, and reproducible calculations. Code is not the target. Unit tests, CI/CD, packaging, app architecture, and engineering ceremony are not success criteria unless a specific research artifact truly needs them.

The target is decipherment evidence:

- Build a source register.
- Define what "accurate like Ancient Egyptian" would mean under unfair conditions.
- Reproduce known statistical and structural findings before making new claims.
- Design experiments that distinguish language, nonlinguistic emblem systems, administrative notation, and mixed systems.
- Turn any proposed sign reading into a falsifiable claim.
