## Segmentation Scenarios

The live best explanation is not a reading. It is a source-layer model:

```text
700-034 may be a two-part local encoding of Parpola's standardized UIII cluster.
```

That is only a candidate. The adversarial alternatives remain live:

| Scenario | Status | Test |
| --- | --- | --- |
| Composite cluster split locally into `700-034` | Preferred live hypothesis | High-res no. `532` shows U/V body plus adjacent three-stroke group; `M-478/M-480/M-1425` show same body plus four-stroke `004`. |
| Marshall counts visible components, lipi counts signs | Live control | Other rod descriptions show descriptive counts can diverge from sign-list token count. |
| Local under-segmentation | Live adversarial | CISI/M77 gives five source units that cannot be grouped into four local tokens. |
| Parpola compound notation masks token count | Live control | Parpola sign-list convention shows whether `UIII` is one sign, sign-plus-strokes, or shorthand. |
| Direction/order mismatch | Live but source-dependent | `700` and `034` must be adjacent under raw source orientation. |
| Wrapper/base graphic plus internal strokes | Live visual test | High-res image shows strokes integrated with the U/V element. |
