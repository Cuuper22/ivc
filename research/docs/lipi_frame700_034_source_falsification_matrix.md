# Lipi FRAME700 034 Source Falsification Matrix

Date: 2026-05-25

## Purpose

This note writes down, in advance, what would change our minds. FRAME700 is the project's label for short inscription rows built on sign `700`, such as `+700-034+`; the `034` residue is a leftover pattern involving sign code `034` that the controls run so far have not explained. The matrix defines what source-image observations would kill, downgrade, or upgrade that residue. It is deliberately stricter than the local statistical packet — the bundled list of objects assembled from our own records. Writing the kill conditions before looking at the images is what stops the images from being read to fit.

The live claim before source validation is only:

```text
034 is a distributional residue inside FRAME700 and has matched 033/032 controls worth checking.
```

It is not a reading.

## Matrix

Controls are comparison objects carrying `033` or `032` that match the `034` object closely; a triad is one such set of three, one object per sign code. A copy family is a set of objects carrying the same inscription that may be copies of one another.

| Source observation | Impact | Required evidence |
| --- | --- | --- |
| The target sign is not visually `034`, or could equally be `033`/`032` under normal drawing variation | Kills the `034` lead as transcription/allograph noise | High-resolution source image or plate showing strokes; side-by-side comparison with matched `033` and `032` controls |
| `+700-034+` order reverses or collapses under source direction | Kills formula-level contrast or downgrades to direction artifact | Original image direction, impression/copy status, and the same reading convention applied to target and controls |
| Target side assignment is wrong, copied, or only editorial | Downgrades from ancient pattern to catalog artifact | Evidence tying the `034` row and companion row to the same physical object and physical side relation |
| Target is one member of a duplicate/copy family with no independent attestations | Downgrades to copy-family effect | Mold/object-family assessment, publication-cluster check, and support counts after excluding near-copy rows |
| Companion long-side row is misread, absent, or not physically paired | Kills that triad's contextual force | Source confirmation of the long-side sequence and physical relation to the `034` side |
| Target differs from controls mainly in size, material, shape, or preservation | Supports object-format association only | Matched comparison showing `034` tracks object format while side/context behavior does not differ source-visibly |
| Target and controls are same format, source-comparable, and `034`/`033`/`032` stay visually distinct | Upgrades to stable FRAME700 slot contrast; still no reading | Source-safe triad with distinct signs, matched metadata, validated side relation, and confirmed long-side context |
| Multiple independent `034` rows repeat a source-confirmed pattern while matched controls lack it | Upgrades from object artifact toward scribal/administrative distribution | Non-duplicate attestations across independent families plus matched `033`/`032` controls |
| `034` contrasts with `033` inside the same or near-same long-side family but different physical side relation | Stronger upgrade: subtype is not just long-family membership | Same/near-same long-side sequence family, same format, different FRAME700 subtype, validated side relation |
| `034` remains distinctive after removing all direction-risk and duplicate-risk rows | Strongest current upgrade path | Clean subset: source-confirmed sign, direction-safe, family-independent, matched controls, preserved residue |

## Decipherment Standard

By Egyptian or Linear B standards, this is still pre-reading. Mature decipherment needs independent constraints: repeated sign contrasts, stable contexts, external anchors, and predictions that survive new evidence.

Champollion had bilingual and proper-name leverage. Ventris had grid constraints, alternations, place-name predictions, and administrative contexts. The current `034` path has none of that yet. The honest ceiling after a future source pass, if it actually survives this matrix, would be only:

```text
A future matrix-passing result could upgrade only the FRAME700 034 distributional contrast evidence, not its meaning.
```

That ceiling has not been reached in the current evidence state.

Not:

```text
034 means X.
034 is a number.
034 has a phonetic value.
034 translates as X.
```
