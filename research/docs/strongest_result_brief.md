# Strongest Current Result

Date: 2026-05-30

The strongest accepted result is structural, not phonetic: in the fixed `002-861` branch, `533-717` is a real repeated terminal tail in the current strict local layer.

The claim is intentionally narrow. Across 4,135 strict raw rows and 3,074 exact `text/site/type/symbol` dedup rows, the forger searched all units of length 1, 2, and 3 for support >= 2 where every occurrence is a terminal tail after fixed prefix `002-861`. The only survivor is:

```text
M-376 +740-100-176-002-861-533-717+
M-391 +405-845-686-740-793-003-233-805-002-861-533-717+
```

The worst recorded false-positive rate is 0.006. The cleanest context-shuffle controls are lower: 0.0002 globally and 0.0010 within `site/type/symbol` blocks for strict raw rows; exact dedup gives 0.0004 and 0.0006. Both rows are source-visible in CISI India as same-line terminal-side material, and exact copy-family collapse is rejected. The skeptic boundary is just as important: if any prefix is allowed, repeated terminal bigram cells are common, 96 in strict raw rows and 40 after exact dedup. So this is not a global uniqueness claim. It is a fixed-prefix `002-861` structural finding.

What it earns: one accepted structural finding in the ledger. What it does not earn: exact source-normalized `861/533/717` token boundaries, sign value, sign meaning, sound, language family, external anchor, or translation.

The strongest broad instrument remains Vector 2: in the strict exact-sequence-collapsed Lipi working corpus, local sign context is measurably constrained, but the corpus remains far from phonetic unicity. This is a publishable-shaped negative result against internal-only language identification, and a usable measuring instrument for future anchors.

The run uses `data/open_prototype/reports/lipi_scope_rows.csv`, filtered to `readiness_bucket = lipi_numeric_clean_candidate`, then collapses exact numeric token sequences. That leaves 1,798 sequence families from 2,883 strict rows, with 8,212 sign tokens and 571 distinct numeric signs at full coverage.

The core positive fact: a leave-one-row-out masked-sign model recovers the true hidden sign at top-1 accuracy 0.279591 and top-5 accuracy 0.534096. The top-1 result survives six forger controls at 100 iterations each, with recorded false-positive rate 0 for every tested control: global token shuffle, row-internal shuffle, position-slot shuffle, edge-frame shuffle, register-blocked position shuffle, and a template administrative code generator. This supports only the narrow claim that the corpus has local context constraint beyond those controls.

The core negative fact: the same corpus has an unanchored phonetic label-symmetry lower bound of log2(571!) = 4,410.970864 bits. Internal distribution can say that a sign fits a slot better than another sign, but without an external value anchor every proposed phonetic alphabet can be globally permuted into an equally good internal solution. Allowing nulls, allographs, homophony, or polyvalence only expands that space.

The known-script calibration matters. Linear B Series D, reduced to Indus-like row lengths and with readings hidden from the model, gives clean bidirectional masked top-1/top-5 = 0.435897 / 0.698006. Under the harsher source-provided gapped sequence-leave-one-out test, Linear B drops to 0.294314 / 0.638796. SumTablets adds a second known-script point: 1,798 glyph-only Ur III administrative cuneiform line sequences, transliteration hidden, score 0.171753 / 0.373681 and beat their own five matched controls with max null >= observed share 0. Indus top-1 is in the neighborhood of the harsher Linear B missing-sign task and above this SumTablets glyph-only line sample, but Indus has 571 signs versus 91 Linear B tokens and 358 SumTablets glyphs in the capped comparators. The label-symmetry burden is still the thing a decipherment claim has to pay down.

The nonlinguistic comparator prevents the cheap overclaim. A broader bidirectional predictor looked tempting at top-1 0.325865, but structured administrative, emblem, and mixed admin/emblem forgers exceed it in every rerun iteration. Their null means are 0.472924, 0.443351, and 0.415069. A real-world comparator from the Sproat 2014 XML bundle tightens the boundary further: Pictish stones score 0.450292 / 0.614035 and barn stars / hex signs score 0.367123 / 0.673973 under the same masked-symbol task, both above Indus top-1. So masked local predictability is not language evidence either.

The sharper positive signal is directionality. A leave-one-row-out bigram model scores each stored sequence against its reversed sequence. In the strict exact-collapsed Indus scope, stored order wins in 0.947720 of rows. Under the harsh scope that removes top edge signs and collapses one-edit families, stored order still wins in 0.841096 of rows, with max null >= observed share 0 across global-token, row-internal, position-slot, and edge-frame shuffles. Current real-world nonlinguistic and ambiguous comparators do not reach that harsh Indus value; the strongest is Pictish at 0.802139. Known scripts do exceed it: Linear B Series D is 0.996403 and SumTablets is 0.935484. A Mayig P-namespace pressure test finds exact-collapsed stored-order asymmetry too, 0.943750, but its harsh scope drops to 0.666667 over only 24 rows. The matched Lipi/Mayig overlap no longer counts as support: after top-edge removal and block-conditioned controls it drops to Lipi 0.363636 and Mayig 0.473684, each with max null >= observed share 1.
