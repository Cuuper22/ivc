# H-942 / H-2240 / H-2241 Source Normalization Gate

Date: 2026-05-26

This note is a gate — a checkpoint the evidence must pass before the project may take a further step. Published work claims three more objects carry the same text as a group already under study. If that were true and checkable, it would widen the evidence base. This note works out why it does not, yet: one of the three reads differently in the local transcription, and the other two have no usable published photograph.

## Question

Parpola 2019 says the obverse text of the H-940 / H-2147 / H-2148 group also occurs on H-942, H-2240, and H-2241. Does that let us use H-942, H-2240, and H-2241 as source-normalized evidence for the H-2148 companion row, or does it keep the branch source-gated?

## Decision

It keeps the branch source-gated. A branch is one open line of investigation; source-gated means it cannot advance until better source images or catalog notes arrive.

The useful linguistic fact is not a reading. It is a source-normalization split:

```text
H-942 is source-visible but locally terminal-different: +520-220-016+
H-2240 is locally exact: +520-220-415+, but source-dark in the checked public layer
H-2241 is locally fragmentary: ]415-240+, and source-dark in the checked public layer
```

Source-dark means no usable published photograph of the object was found in the layer checked. That means Parpola's recurrence statement is real prior-work pressure for a companion-text family, but it is not a closed local sign crosswalk — a sign-by-sign alignment between his numbering and the project's own.
