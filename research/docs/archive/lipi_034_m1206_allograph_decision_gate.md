# Lipi 034 M-1206 Allograph Decision Gate

Date: 2026-05-26

This note is the standing decision board for one narrow sign question. Two sign codes, `034` and `415`, appear in the same three-sign frame. Either they are two spellings of one sign, or they are two different signs that happen to look alike, or the difference is an artifact of how sources label sides or how the project transcribes. The note lays out those four possibilities side by side, records which evidence each currently has, and states exactly what would settle it. It is a gate — a checkpoint the branch cannot pass until one of those hypotheses wins.

## Question

After closing the H-786/H-941 side-policy gate, what is the next admissible linguistic decision for `M-1206 +520-220-034+`? Allography is the question of which shapes count as variants of the same sign.

The live question is not "what does 034 mean?" The live question is:

```text
Inside the 520-220-X frame, are local 034 and 415 separate signs, allographs, source-side artifacts, or transcription-policy splits?
```

No translation system can honestly use this branch until that sign-inventory question is controlled.

## Hypothesis Matrix

### H1: `034` and `415` are allographs or one broad graphemic family

Current support:

- M-1206 target terminal components are internally stable.
- Isolated M-1206 terminal components cluster closest to exact-side `H-938 A/A bis` `415` controls.
- `H-940 A` provides a second clean exact-side `415` control, though weaker in the isolated terminal view.
- Prefix/nonterminal distractors — decoy crops from the non-final part of the same inscription, included to see whether reviewers match on context rather than form — were rejected, so the match is not only shared `520-220` context.

Current blockers:

- Only one exact `+520-220-034+` object exists in the local frame.
- The closest vertical-bundle `415` controls are Harappa tablets, not same-site seals.
- Same-site `M-37` is now cleanly recut, but its comb/rake-with-stem profile is not the closest visual neighbor to M-1206's vertical-bundle terminal.
- No independent source-visible `034` terminal target currently confirms the M-1206 terminal form.

Upgrade condition:

```text
At minimum: source-grade M-1912/M-1206/M-37 triad plus one independent source-visible 034 terminal/near-terminal witness must keep the same diagnostic terminal form under blind classification, while M-37's same-site comb/rake control remains separated or explained.
```

### H2: `034` and `415` are separate signs inside a similar visual family

Current support:

- M-37 now supplies a clean same-site `415` comb/rake-with-stem control that is visually distinct from M-1206's tighter vertical-bundle terminal.
- H-940 is weaker than H-938 under terminal isolation.
- The corpus keeps `034` and `415` as distinct local signs, and no source-level proof currently collapses them.

Current blockers:

- The cleanest exact-side terminal controls, `H-938 A/A bis`, are visually close to M-1206.
- The nonterminal distractor test makes a pure "shared prefix" explanation insufficient.
- Local `415` now has at least two source-visible profiles in this branch, so M-37's distinctness could be `415` internal variation rather than a clean `034/415` separation.

Upgrade condition:

```text
Clean, source-normalized terminal crops must show M-1206 target witnesses clustering apart from both the vertical-bundle `415` controls and the same-site M-37 comb/rake control while independent `034` witnesses cluster with M-1206.
```

### H3: the conflict is a source-side mapping artifact

Current support:

- H-786 and H-941 proved that local `.1/.2` and CISI `A/B` cannot be globally equated.
- Close visual panels on H-786/H-941 are exactly the kind of evidence that can be misweighted by side-label confusion.

Current blockers:

- H-938 and H-940 remain clean exact-side controls after the policy gate.
- The strongest terminal control is H-938, not a side-gated object.

Upgrade condition:

```text
Object-specific side-label/transcription notes must show that one or more clean controls are assigned to the wrong local row or that the local 034/415 distinction is produced by side assignment rather than glyph form.
```

### H4: the conflict is a transcription-policy split

Current support:

- M-1206 terminal and clean 415 controls share a terminal graphic family, but current local codes split them.
- H-938 places exact-side `+520-220-415+` on one side and `+034-700+` on the companion side, creating within-object proximity pressure.
- The follow-on H-938 same-object source-panel audit verifies this as source-visible panel evidence: `A/A bis` is local `1818.1 +520-220-415+`, with `A bis` only a duplicate photograph, and `B` is local `1818.2 +034-700+`.
- The companion-context inventory shows this is not locally unique: exact `+520-220-415+` has four local `034/700` companion objects (`H-319`, `H-938`, `H-939`, `H-1284`), but only H-938 is currently clean source-panel-audited.
- Prior `M-315` work already showed that local `034` can face pressure from visually neighboring code classes.
- The later `H-938 B` component probe is negative for direct component-level `034/415` support: the B-side component closest to the vertical `415` family is not the candidate `034` under the local `R/L` order assumption. `H-319` and `H-1284` remain acquisition-only. No allograph decision follows from the companion pattern.

Current blockers:

- There is no explicit source-transcription note saying the same glyph was split as `034` versus `415`.
- `H-938 +034-700+` is a companion-row proximity fact, not a terminal equivalence.
- The current evidence can still be explained by separate signs in a visual family.

Upgrade condition:

```text
Find source or cross-list evidence where the same diagnostic terminal form is transcribed as 034 in one controlled context and 415 in another, with side labels and direction fixed.
```

## Current Decision

The branch is stronger than it was before the terminal-component gate, but it still does not cross the allograph threshold.

Accepted now:

```text
M-1206 has a stable source-visible terminal component.
The closest clean external terminal controls are exact-side H-938 A/A bis 415.
H-940 A is a secondary clean exact-side 415 control.
M-37 now supplies a clean same-site 415 terminal control, but as a comb/rake subform rather than the closest M-1206 match.
The match is not explained only by the shared 520-220 prefix.
The active explanation space is allograph vs separate visual-family sign vs source-side artifact vs transcription-policy split.
```

Not accepted:

```text
034 = 415
034/415 allograph status
034 or 415 sign value
semantic value
phonetic value
translation
```
