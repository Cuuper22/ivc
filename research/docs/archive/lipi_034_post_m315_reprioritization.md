# Lipi 034 Post-M315 Reprioritization

Date: 2026-05-26

This note is a re-ranking. A blind test had just failed: seal `M-315`, the object we were leaning on hardest, did not hold up. This is the record of choosing where the work goes next, written on the day the setback happened rather than reconstructed later.

Some vocabulary used below. A branch is one line of investigation. A gate is a test a claim must pass before the project builds on it. A blind sort or blind review means reviewers judged images without knowing which object they came from. An allograph is a different drawn shape for the same underlying sign. Quarantined means an item is held out of the evidence pool until its problem is fixed.

Supersession note, 2026-05-26: the M-1206 branch selected here has now been executed through three follow-on gates: [M-1206 cohesion gate](lipi_034_m1206_034_cohesion_gate.md), [M-1206 terminal component gate](lipi_034_m1206_terminal_component_gate.md), and [M-1206 allograph decision gate](lipi_034_m1206_allograph_decision_gate.md). Use this document for why M-1206 was chosen after M-315 failed; use the allograph decision gate for the current post-side-policy hypothesis state.

## Question

After the strict M-315 blind sort failed to upgrade local `034`, which `034` branch should carry the next source-visible decipherment experiment?

This is a sign-grounding decision, not a reading. The question is whether local `034` survives as a coherent graphic class when source images are treated as primary evidence.

## M-315 Result That Changes The Queue

The M-315 branch no longer counts as live positive `034` evidence.

A packet is a self-contained bundle of evidence and rulings. The strict `390-X-002` blind packet found that the strongest pair was:

```text
S003 = M-984 impression a, local 004 control
S005 = M-315 upper face, local 034 candidate
```

The lower M-315 impression did not independently join that pair. That fails the required upgrade condition: both public witnesses needed to preserve a distinct source-visible `034` class against the matched controls.

This does not prove `M-315 = 004`. It creates upper-witness `004` pressure and removes M-315 from the positive evidence pool until higher-resolution source imagery or an independent source transcription changes the result.

## Why M-1206 Is Next

M-1206 is the only immediate branch with all of these properties:

```text
direct CISI source image
local exact 034 row
same-site source-visible comparator
tight formulaic frame
existing blind visual result
clear falsification criteria
```

A frame is a fixed run of surrounding signs with one slot left open, so rows sharing it can be compared position by position. The frame is:

```text
M-1912  +520-220-003+  source still gated
M-1206  +520-220-034+  source-visible target
M-37    +520-220-415+  source-visible comparator
```

The already-run source image comparison found the same broad three-class face pattern on M-1206 and M-37:

```text
T = triangular / standard-like sign
L = split leaf / fish-like sign
R = rake / vertical-stroke bundle sign
```

Observed orders:

```text
M-37 A       R-L-T
M-37 a       T-L-R
M-1206 A+E   R-L-T
M-1206 A     R-L-T
M-1206 a     T-L-R
```

That weakens the naive terminal-substitution story. If the source images already share a broad pattern, then the real research question is no longer "what does 034 mean?" It is:

```text
Are local 034 and 415 separate signs, allographs, source-side mapping artifacts, or transcription-policy splits inside the same visual family?
```

## Current Evidence Against Easy Translation

The `415` fine-form packet — a study of small shape details rather than broad silhouette — added public source-visible candidates beyond M-37. It found repeated target-like broad patterns at:

```text
H-786 A
H-938 A / A bis

```

But it did not settle stable fine-form identity. Exact-side `415` evidence is currently strongest for `H-938 A/A bis` and `H-940 A`; `H-786` and `H-941` remain source/local side-mapping gates.

That matters because M-1206's terminal unit can no longer be read as a clean semantic contrast just because the local numeric code is `034` while M-37 has `415`. The image evidence has made local sign identity itself the object of study.

## Next Decisive Experiment

Run a M-1206-centered `034` cohesion gate. Cohesion here means: does everything we label `034` actually look like one sign?

### Hypotheses

Three rival explanations, each with the observation that would confirm it. Writing all three down at once keeps the favourite from being the only one tested.

```text
H1: 034 is a stable source-visible sign class in this branch.
Prediction: M-1206 terminal form remains visually distinct from source-visible 415 comparanda after side mapping and orientation controls.

H2: 034/415 are allographs or transcription-policy splits.
Prediction: M-1206 terminal form clusters with some source-visible 415 panels under blind fine-form review, especially after A/a mirroring and source/local side mapping are corrected.

H3: 034 is not a single graphic class across the P0 set.
Prediction: M-1206, M-315, M-685, M-1584, and M-2104 fail to form a coherent visual class even after object type and damage are controlled.
```

### Positive Result

M-1206 stays live as a source-grounded `034` class only if:

```text
M-1206 terminal remains distinct from the 415 rake/bundle class under blind review
M-37/H-938/H-940 exact-side 415 controls stay internally coherent
M-1912 or another 003 comparator enters with source-grade image control
M-315 upper-004 pressure stays quarantined instead of defining 034
```

### Negative Result

M-1206 downgrades from target `034` to allograph/transcription-policy pressure if:

```text
M-1206 terminal clusters with exact-side 415 panels
side mapping explains the local numeric difference better than visual form does
new source-visible 034 candidates split by object type rather than sign shape
```
