# Lipi 034 M-1206 M-1912 Source Gate

Date: 2026-05-26

This note is a gate — a checkpoint the evidence must pass before it can be used — and it turns down an object the project badly wants. `M-1912` is the ideal control: same site, same material, same three-sign frame, different final sign. Everything about its design is right. The only problem is that no raw source image of it has been inspected, and wanting a control is not the same as having one.

## Question

Can `M-1912 +520-220-003+` be admitted as a source-grade same-site terminal control — an object from the same site used as a comparison case — for the `M-1206 +520-220-034+` branch?

## Decision

No. `M-1912` is a real local same-site control target, but it is not source-grade yet.

Current status:

```text
M-1912 = secondary_visual_lead_only
research use = same-site 003 terminal acquisition target
source-grade use = rejected until CISI 3.1 or equivalent raw object source is inspected
accepted mapping/value/translation = 0
```

This does not weaken the importance of `M-1912`. It clarifies its role. It is the missing Mohenjo-daro non-034/non-415 terminal control in the tightest `520-220-X` frame, but using it as if the raw source image were already checked would contaminate the branch.

## Admissibility

`M-1912` passes the linguistic/control-design criterion but fails the source-admissibility criterion.

It passes because it is exactly the control we want:

```text
M-1912 +520-220-003+
M-1206 +520-220-034+
M-37   +520-220-415+
```

All three are local Mohenjo-daro `SEAL:S`, steatite, square, class `MT`, three-sign, `R/L` rows with fixed prefix `520-220`. That is a genuine terminal-slot contrast frame.

It fails because the current `M-1912` image layer is secondary. The RMRL/Bhaskar figure is useful enough to keep the route alive, but not enough to decide whether local terminal `003` is graphically separate from, aligned with, or analytically comparable to `034/415`.

## Effect On The M-1206 Branch

No branch hypothesis is promoted by this gate.

Still live:

1. `034/415` are allographs or one broad graphemic family.
2. `034/415` are separate signs inside a similar visual family.
3. The apparent similarity is a source-side or side-label artifact.

- `M-1912` remains the missing same-site `003` control.
- No blind component packet — a bundle of label-stripped crops sorted without the reviewer knowing which is which — may use `M-1912` as a clean witness until a source-grade crop exists.
- The next source action is precise: inspect `M-1912` in CISI 3.1 or obtain an equivalent raw object/photo/source-transcription record.
